# Function coverage: original functions the 1.0 route runs vs. what the port cites

Generated by `tools/function_coverage.py report` on 2026-11-27. Addresses, counts and guesses only; no retail bytes. Every "guess" is CANDIDATE (heuristics over the function's own instructions: hardware registers, GTE ops, known globals and known callees), not a reading of the code.

## How it was made

- **All functions:** Ghidra 12.1.4. ROCK_NEO.EXE from the saved, pre-analysed project (`ROCK_NEO_mcp`); each overlay `R3_STxx.BIN` imported raw at 0x80100000 and seeded with prologues after `jr ra` plus data words pointing at prologues, then auto-analysed.
- **Ported:** every `0x8xxxxxxx` in `src/ include/ platform/3ds/source/ tools/ tests/` (git-tracked). An address inside a function covers it. Overlay addresses go to the stage named on or near the line, else the file's main stage, else ST00.
- **Executed:** psxrecomp oracle (US disc) with the debug-only per-function counter (`tools/psxrecomp_fn_hist.patch`): compiled-function entries plus psx_dispatch and interpreter JAL/JALR targets. Each M3 savestate (`saves/m3/*.pst`) was loaded and run for 3000 frames: two thirds idle (the event in progress plays on), one third walking forward with Circle pressed every 40 frames and a turn every 400. The overlay was identified by its first 64 bytes; a run that changed stage was split. Counts are calls during those runs; overlay counts may include a few duplicates (an interpreted call into a compiled overlay function counts twice).
- **Extra states:** the oracle's savestate slots 1–10 (other sessions' scratch states, mostly the M1 tutorial and the tutorial boss) were also replayed, read-only via a copy in slot 11; they give the ST00 rows. "Runs" counts savestate runs (segments) with that image loaded.
- **Names:** PsyQ library names come from the older `ROCK_NEO_psx` Ghidra project (ghidra_psx_ldr signatures); everything from `__main` (0x80067FF8) up is PsyQ SDK code. Game-function names marked "MML1x10" come from the public WIP decompilation [MML1x10](https://github.com/JoshuaDav10/MML1x10) (`config/syms.us.rock_neo.txt`, 337 symbols, not yet matching/shiftable), so a public decompilation exists but covers few functions.
- **Not covered by the oracle runs:** the title/menu/new-game path, ST00 areas no slot state sits in, rooms the M3 saves only pass through (teleport shortcuts, see M3_ROADMAP.md), and the Tron fight beyond its start. A function that runs only there cannot show as executed here, so "not executed" is not proof of "unused in 1.0".
